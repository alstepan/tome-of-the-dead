# HOW TO PLAY screen (INSTR1) - render spec. Layout B, 2 pages. Source: docs/design/instructions_screen.md
# Lines starting with '#' or '===' are NOT screen rows. Every page = exactly 24 screen rows
# (row 00 .. row 23), each <= 42 chars, after the "=== PAGE n ROWS ===" marker.
# Text: FONT6 6x8, char k starts at x = 6*k px (k = 0..41, x 0..251), row r at y = 8*r px.
# Icons/tiles: 8x8 attribute CELLS, cell c at x = 8*c px (c = 0..31). Icon area chars are spaces.
# Attr = Spectrum byte: BRIGHT bit 6, PAPER bits 5-3, INK bits 2-0. PAPER is 0 (black) everywhere
# unless stated. $47 = INK 7 white, BRIGHT 1 | $07 = INK 7, BRIGHT 0 | $46 = INK 6 yellow, BRIGHT 1
# $06 = INK 6, BRIGHT 0 | $45 = INK 5 cyan, BRIGHT 1 | $05 = INK 5, BRIGHT 0 | $42 = INK 2 red, BRIGHT 1
# $43 = INK 3 magenta, BRIGHT 1 | $00 = blank. Border black. No FLASH.
