# ITEM-INFO: item and treasure properties in the bag page; HOW TO PLAY dropped

Status: **APPROVED with the §9 defaults (user 2026-11-12).**

Designer, 2026-11-12. User decision 2026-11-12: the bag page is the always-available reference for
item and treasure properties. Tutorial v2 (roadmap 4c) only points at it. HOW TO PLAY and roadmap
item 5 are dropped, and their boot streams are reclaimed. Supersedes game.md §3.2.1,
`instructions_screen.md` / `.txt` and `instructions_treasures.md` (they get archived, §7).

## 1. Where the info goes (decision: the bag page only)

- **Bag page, rows 18–19** (game.md §8.11 Q3; `page_ovl.asm` `pg_info`). The description icon stays
  at cells 0–1, rows 18–19. Text starts at x = 16 (cell 2) in FONT6 (6×8), so a row holds
  **40 chars** (k = 0..39 at x = 16 + 6k). Today only row 19 is used (name + `it_fmt`). Row 18
  next to the icon is blank.
- **ICON MODE row 20: unchanged.** FONT6, 42 chars, but 3 fixed fields (0–15, 16–27, 28–41): the
  longest is 14 chars, too short for a phrase; row 20 is shared with the target readout and the D0
  goal line; gear is not on the bar. A pager would cost hot-path code to repeat the page.
- **Too long: never at run time.** Every phrase and every composed row is ≤ 40, checked at pack time
  (§3): no wrap, no pager, no truncation. Abbreviations only as today: `DMG MP HP ATK DEF 1Dn 2X`.

## 2. Page layout (rows 18–19 replace the as-built row 19)

```
cells   0 1 | 2 ............................................. 31
chars       | 0         1         2         3        39   (x = 16 + 6k)
row 18 [icon] NAME[ Xn][ +v | WORN OUT][ 1Dn+b][ ATK+n][ DEF+n][ MP+n][ DODGE+n]   attr $47
row 19 [icon] EFFECT PHRASE[, GATE PHRASE]                                         attr $05
row 20  verb strip (as built)       row 21 blank       row 22 message row (as built)
```
- Row 18 is the as-built `pg_info` line (`item_name` + ` Xn` + `it_fmt`), moved up from row 19
  (`PG_DESC_ROW` 19 → 18). One change: `it_fmt`'s ` EVA` becomes ` DODGE`, the word the treasures
  page taught (+2 B R6). The longest line is `WARLORD CLEAVER +5 1D10+6 ATK+1` (31). WU2 stays ≤ 37.
- Row 19 is new: the type's **effect phrase** (stored, §3), then `, ` + the **gate phrase** if the
  type is METAL or CLOTH (gear_rules.md §1.1). Both are optional, and the row stays blank when there is neither.
- Attrs: row 18 text cells `$47`, row 19 `$05`, icon cells the item ink (whole-row attrs: no clash).
  Empty bag slot: `EMPTY` on row 18, row 19 blank; `[CLOSE]` blanks both; an empty worn slot shows
  its placeholder + `EMPTY`. Worn row and bag grid show the same text for the same item.

Gate phrases: METAL `BLOCKS MAGE SPELLS` (18), CLOTH `BLOCKS POWER ATTACKS` (20), shown to both
heroes. Uniques and charms have no gate; the missing phrase is the cue (replaces the "never do" line).

**Identification rules (never reveal what the game hides).** There is no ID system (game.md §8.11
rev 6): names, q and m are already public, so row 18 shows only what `it_fmt` shows today (v = m + q
as one number, `WORN OUT` at m = −3). It never shows m and q apart, or wear odds or chances. Blessed /
cursed do not exist: nothing to show. Things decided at use stay hidden: a Tome's outcome (decided
at READ by the §5 steps; the phrase says "a new skill or a rank" and never which one), the Teleport
destination, and Enchant's target. **Charges:** no item has charges, and stacks show ` Xn`.
**Turns:** only Fear 6 and Sleep 8 (`SCR_FEAR_T`, `SCR_SLEEP_T`, fx6.asm). These are literal digits in the
phrase, kept in step by a test (§6), the same as the Enchant cap +3 and the spell bonuses +1 / +2.

## 5. Removing HOW TO PLAY (BOOT4 reclaim)

**Goes.** `GS_HELP1`, `GS_HELP2` (already unused) and `GS_HELP3`. In `instr_ovl.asm`: `in_page`, `in_vblk`, `in_cell`, the page part of
`in_flow` (page 1, `in_wait` BREAK skip, page 2), and the page-1 / page-2 streams in the bank-4
BOOT4 block (raw 772 + 702 B, plus icon and attr records). Also `tools/instr_pack.py`,
`tools/gen_instr_mock.py`, `build/text/instr_p*.inc` and the mock PNGs, the `INSTR_DATA` unpack area,
and the bank-1 key-label / bar-icon staging and R6 `ic_scr` calls made only for the pages.
**Survives (the overlay stays).** `in_flow` reduced to `in_ft` (frame_tab, first in BOOT4), the
loading picture + `PRESS ANY KEY` (`GS_ANYKEY`; release-first, key swallowed), then `in_tut` (D0 blob
→ `BLOB_ORG`, `in_stub`, `es_go` patch). The BOOT4 trailer and `TT_BOOT4_REC` are unchanged.
**Reclaim:** the page streams and code leave tape and BOOT4 (estimate ≈ 1.1–1.3 KB packed, a few seconds
of loading). This is boot-only space: it does **not** fund §4's resident bytes. It gives the D0 blob
more room (blob spare is 8 B today) for Tutorial v2's lines.

**The tutorial pointer's new home: the main menu, row 10** (between `1 START` rows 8–9 and
`2 HERO` rows 11–12; the same FONT6 sub-line style as rows 16 / 20), cols 0–20 (left of the hero
preview at col 21) = 28 chars: **`NEW HERE? START > 1 TUTORIAL`** (28), attr `$45` (Morrow's ink).
It is drawn only while the tutorial is offered (the `ts_choice` state, §3.2 TUT0) and blank once D1
has been entered. It replaces the boot reference, and the choice screen after START keeps
`BROTHER MORROW WILL TEACH YOU`. Engineer: check that the preview leaves row 10 cols 0–20 clear.
