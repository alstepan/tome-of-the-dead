## Assumptions

* Level kinds = game.md section 9.1 Depths column; Ogre on D4 and Death Knight on D7 always (lair), Archmage D8.
* Lean sets (HURT = flash; DEAD shared per body class): Spider walk1/2 + bite; **Orc walk1/2 + attack (Orc is not in the 2026-10-20 lean ruling: assumed like Mummy)**; Necro walk1/2 + cast; Mummy walk1/2 + attack; Ogre walk1/2 + slam; Death Knight walk1/2 + cleave + block; Archer = Skeleton walk1-4 (shared) + 1 shoot frame; Vampire and Archmage = Necro frames; Necro bolt 3 frames. New-kind walk1 = MOT (it is the rest frame, like Rat/Skeleton walk1), walk2 = WK0.
* Shared DEAD: `dead_humanoid` (40x16, knight_dead geometry) once per level with any new humanoid kind; Spider shares `rat_dead` (counted only when Rat is absent). If the humanoid DEAD were instead an existing frame (e.g. skeleton_collapsed) levels with that kind save its cost (320 B).
* Arrows (3 frames, 160 B) are added for the Mage on levels with an Archer; the Warrior's FX already holds them. Necro bolt frames (256 B) on Necro / Archmage levels.
* Fixed part as `data.asm` POOL_NEED: 2 select idles + 3 x 576 straddle = 2,880. Hero: Warrior = Knight + K_FXW = 15,840; Mage = Wizard + K_FXM = 11,648.
