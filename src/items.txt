# src/items.txt — 3E item names, message stems and per-type numbers (3E-T4).
# THE single source for tools/itempack.py (-> build/text/items_tab.asm,
# items_ovl_stems.asm, items_ids.inc) and tests/itemtab.py.
# Spec: docs/design/game.md §8.11 "3E text rulings (2026-10-20)", §8 gear/food
# tables, §8.6 uniques, §8.8 light ID.
#
# Lines: '#' starts a comment, blank lines are ignored. A section starts at [name].
#
# [buc]     word-table seeds, one per line: BLESSED, CURSED (the BUC prefixes).
#
# [appear]  light-ID words, in appearance-index order (each run must be contiguous
#           in the word table; the tool checks it):
#             potion RUBY=$02 AZURE=$05 EMERALD=$04 AMBER=$06 VIOLET=$03 MILKY=$07
#             scroll ZORAK VELMIS OSTRUN KAPPU MIRADEL THUNE YOLQ ABRAXA
#           The =$xx on a potion colour is its appearance ink (app_attr, §8.8).
#
# [book]    the two words the hero-tome marker stands for, one per line: WAR, SPELL.
#           IT_BOOK's name is "<HERO> TOME": <HERO> is packed as the id $FF (ITN_HERO).
#           CONTRACT for item_name (T10): $FF -> W_WAR when HERO_KIND is the Warrior
#           (knight/warrior), W_SPELL for the Mage; the TOME word is shared.
#
# [types]   one row per type id, each id once, ids 0..43 (IT_* in item_defs.asm; IT_COUNT 44):
#             IT_NAME | NAME | INK | DIE ATK DEF MP AMT | FLAG | NOTE
#           NAME    1..3 words separated by single spaces, or '-' (no name).
#                   Potions/scrolls: the KNOWN name; unknown names are composed
#                   from [appear] ("<colour> POTION", "SCROLL <label>").
#           INK     $xx (floor / inventory ink, §8.11 Q1), APP (potion: the
#                   appearance ink from [appear]; packed as $00 in it_attr),
#                   or '-' (= $00).
#           DIE     weapon die sides (0 = none).
#           ATK     signed attack modifier, -8..7.
#           DEF MP  gear only (DEF >= 0, MP >= 0).
#           AMT     food: FOOD restored (§7); potion: HP (Heal, Cure) or MP (Mana).
#           FLAG    U = unique (never carries a BUC prefix, §8.6), else '-'.
#           NOTE    free text, not packed (effects the 2-byte stat cannot carry).
#           Packing into it_stat (2 B per row): byte0 = DIE | ((ATK & $0F) << 4);
#           byte1 = AMT for food/potion rows, else (DEF & $0F) | (MP << 4).
#           Rows with AMT != 0 must have DEF = MP = 0 and vice versa (tool-checked).
#
# [stems]   NAME | GROUP | SRC | "TEXT"
#           NAME   lower case identifier; EQU S3_<NAME> (res) or S3O_<NAME> (ovl).
#           GROUP  res = bank-1 resident block (it_stems, offsets S3_*);
#                  ovl = overlay-only block (it_ovl_stems, offsets S3O_*).
#           SRC    N = new text, emitted in its group.
#                  E:<name> = already in src/strings.txt (bank 0, 0 B here). The tool
#                  checks TEXT == that string's value; it is used only for the
#                  composed-length checks.
#           TEXT   double-quoted, UPPER CASE, printable ASCII, no '"'. Spaces at
#                  the ends are kept (stems are concatenated). Style: no full stop
#                  except the ALARM line (src/strings.txt style).
#
# Composed lines (the checks in tools/itempack.py, LOG_MAX 32):
#   pick / equip / remove / discard  + [BUC] + name   (BUC only on BUC-able gear)
#   eat + food name · drink / read + potion or scroll name (known or unknown)
#   it_was_a + known potion or scroll name · trap_found + dart / gas / alarm / TELEPORT
#   bk_read (E) · read + book name
